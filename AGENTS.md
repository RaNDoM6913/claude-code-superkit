# Working on Superkit

Read [docs/WORKING_AGREEMENT.md](docs/WORKING_AGREEMENT.md) once at the start of
work on this repository. It is the owner's approved agreement for scope,
parallel implementation, review frequency, verification and token economy.
Reuse already loaded rules rather than repeatedly loading the same document.

Use [CLAUDE.md](CLAUDE.md) for repository structure and shipped-component
conventions; task-specific instructions and mandatory acceptance gates still
apply. The working agreement's project section distinguishes contributor worker
routing from the model configuration shipped to kit consumers.

For requests to update downloads, installations or clone counters, first read
[docs/DOWNLOAD_STATS.md](docs/DOWNLOAD_STATS.md) and its linked daily ledger.
Merge counts by UTC date; never add overlapping rolling-window totals.
